# v0.1.0 验收清单

> 状态基线：`origin/main`（2026-09-06 整理）。本文档是 v0.1.0 发布前唯一的验收执行清单，面向执行型 agent 编写：每一步包含前置条件、执行命令、验收标准和结果记录位置。
>
> 执行约定：
>
> - 每完成一步，在对应复选框打勾并在该小节的"执行记录"代码块中追加一行：日期、执行者、结果、证据链接（PR / 日志 / 截图）。
> - 任何一步失败时不要跳过往后走；先修复或记录阻塞原因。
> - 涉及生产数据库或真实 Provider 凭据的步骤标记为 **[需要人工]**，执行 agent 应停下来向用户索取授权或凭据，不得自行猜测。
> - 步骤有依赖顺序，按编号执行。
> - 修复类改动遵循仓库 AGENTS.md 的 Issue / worktree / PR 工作流；本文档自身的勾选更新可以直接随验收 PR 提交。
