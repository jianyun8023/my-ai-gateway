## 范围

- 上游额度：读取失败与真实零值分开，列表与详情提供读取重试；无账号和筛选无匹配使用共享空态及配置/重置入口。

- 共享复选框：关联 label 覆盖实际点击区域；窄屏及粗指针至少 44px，保留紧凑图标与原生切换行为。
- 请求事件：Token、缓存和 TPS 明细使用按钮与 Popover；点击、触摸、Enter/Space 打开，Escape/外部点击关闭。触发器和浮层正文阻止行点击冒泡，行详情入口保留。
- 主题：Key 结果区及来源账号分割线使用已有有效 Token；模型能力详情字号统一使用品牌尺度。未新增主题别名或依赖。
